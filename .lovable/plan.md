# Portfolio-ready README for FlashGenius

## Goal
Replace the default Lovable README with a polished, portfolio-ready writeup suitable for both GitHub and Notion. Title: **"FlashGenius — AI Flashcard & Quiz Generator (July 2026)"**.

## What will be delivered
1. An updated `README.md` containing:
   - Title, one-line tagline, and live demo link
   - The requested resume line
   - Feature list aligned with the app (landing, flashcards, quiz, AI generation)
   - Tech stack and architecture summary
   - AI prompt pipeline / JSON schema explanation
   - Screenshot placeholders for landing, flashcards, and quiz
   - Local setup instructions
   - Project links (live URL, GitHub repo placeholder, LinkedIn post placeholder)
2. A short snippet the user can paste directly into Notion if they prefer a Notion page instead.

## Non-goals
- No code changes to the app itself
- No new routes, components, or backend logic
- No GitHub sync action (the user already knows how to use it)

## Technical details
- File to edit: `README.md` (project root)
- Tone: professional, concise, portfolio-oriented
- Links to use: live site at `https://bright-card-bot.lovable.app`
- Mention tools: TanStack Start, React 19, TypeScript, Tailwind CSS v4, Lovable AI Gateway, Zod

## Success criteria
- README opens with the requested title and resume line
- A recruiter can skim it and understand the project in under 60 seconds
- Instructions are copy-pasteable into Notion with minimal formatting changes
